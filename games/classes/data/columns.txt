# Classes: the English columns (the classes on the board).
#
# Written for English speakers on both sides of the Atlantic: nothing that
# only works in one country, and British and American spellings both count
# (the room decides). docs/classes-design.md §4 is the spec; design/columns.md
# says how this list was written. Check with: npm run columns
#
# `== subject` starts a section (geo bio home music media sport social lang
# break trip register detention). One column a line:
#   TEXT | TAGS | EXAMPLES
# TEXT is a heading of at most 40 characters, with at most one {player} or
# {player's} (filled with a player's name). TAGS, space-separated: party
# (only with party content; detention always is), funny (counts as funny for
# the mix), any (works with every letter), classic:1/2/3 (City, Country,
# River), rule:ends, rule:double, rule:two, rule:long (9+ letters).
# EXAMPLES: `L: answer, answer; L: …`. A column without `any` is dealt only
# for the letters it has examples for, so every example must be right and
# findable in Wikipedia or a dictionary: better a missing letter than a
# wrong answer. Bots answer from the examples, so the funny columns have
# some too. No commas, semicolons, colons or pipes inside an answer.
# Lines starting with # are comments; blank lines are ignored.
