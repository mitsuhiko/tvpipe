# Classes: die eingebauten deutschen Spalten (Stadt, Land, Fluss im
# Klassenzimmer).
#
# Für Leute aus Deutschland, Österreich und der Schweiz geschrieben, nicht
# aus dem Englischen übersetzt (das ist data/columns.txt, eine eigene
# Liste). Siehe docs/classes-design.md §4 und design/columns.de.md.
#
# `== FACH` beginnt ein Fach; die IDs sind fest (geo, bio, home, music,
# media, sport, social, lang, break, trip, register, detention), die
# Namen auf Tafel und Heft stehen in den Seiten (Erdkunde, Biologie, …).
# Dann eine Spalte pro Zeile:
#   ÜBERSCHRIFT | TAGS | BEISPIELE
# - Überschrift: höchstens 40 Zeichen, wie eine Spaltenüberschrift auf
#   dem Zettel ("Stadt", "Ausrede für fehlende Hausaufgaben"). {player}
#   setzt einen Namen aus der Runde ein ("Anna"), {player's} seinen
#   Genitiv ("Annas", "Klaus’"); höchstens einer pro Spalte. Keine nur
#   männlichen oder nur weiblichen Wörter, wo es sich vermeiden lässt.
# - Tags: party (nur mit Inhalt "party"; alles in detention ist party),
#   funny (zählt als lustig für die Mischung), any (passt zu jedem
#   Buchstaben), classic:1/2/3 (Stadt, Land, Fluss), rule:ends,
#   rule:double, rule:two, rule:long (ab 12 Buchstaben), höchstens eine
#   Regel pro Spalte.
# - Beispiele: "B: Berlin, Bern; C: Chur; …". Nur echte Antworten, die man
#   in Wikipedia oder im Duden findet; lieber ein Buchstabe weniger als
#   ein falsches Beispiel. Kein Komma und kein Semikolon in einer Antwort.
#   Umlaute zählen als Grundbuchstabe (Ägypten gilt für A), ein Artikel
#   vorne fällt weg (Der Kommissar gilt für K): solche Beispiele stehen
#   beim Buchstaben nach dem Artikel. Regel-Spalten: jedes Beispiel
#   erfüllt die Regel. Ohne `any` wird eine Spalte nur für Buchstaben mit
#   Beispiel ausgeteilt, mindestens 12 der üblichen 23 (A–Z ohne Q X Y).
#   Lustige `any`-Spalten haben Beispiele für die Bots.
#
# Familientauglich (ab etwa 8 Jahren, mit Oma am Tisch), außer `party`
# und detention. Klassenbuch-Spalten (register) necken, aber nie über
# Körper, Aussehen, Geld, Krankheit, Religion oder Politik; nie gemein.
#
# Prüfen: npm run columns
