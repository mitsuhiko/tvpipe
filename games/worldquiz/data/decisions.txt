# Worldquiz's data: what a human decided (docs/worldquiz-design.md §3).
# scripts/data.ts reads this with the sources and fails, naming the case,
# wherever the sources need a decision that is not here.
#
# One decision per line: `SUBJECT KEY: VALUE -- REASON`. `#` starts a
# comment line. Most decisions need their reason; the script says which.
# Lists are `;`-separated, a pair of lists is `English | German`.
#
#   deck Q…: XX [disputed]      a Wikidata item in the deck with id XX
#                               (the UN's members come from Wikidata; these
#                               are the rest, and UN members without a code)
#   unit ABC: XX | - | drop     a Natural Earth admin-0 unit (ADM0_A3) is
#                               country XX's, nobody's, or not drawn; units
#                               of a sovereign country in the deck need none
#   piece ABC W S E N: XX | -   the polygons of unit ABC whose extent's
#                               middle is in the box go to XX or nobody
#   border XX YY: yes | no      whether XX and YY are neighbours, where
#                               Natural Earth and Wikipedia's list disagree
#   wiki NAME: XX [part] | -    who a name in a Wikipedia list stands for;
#                               `part`: a row for part of XX (its borders
#                               count for XX, its area is not XX's row)
#   ABC area: N                 a part's figures where the World Bank has
#   ABC population: N YEAR      none: km², people, GDP per person (US$)
#   ABC gdp: N YEAR
#
#   XX item: Q…                 Wikidata item for names, aliases, articles,
#                               capitals and flag, instead of the deck's
#   XX name: EN | DE            the short name, where Wikidata's is formal
#   XX aliases: … | …           more accepted answers
#   XX drop-aliases: …          Wikidata aliases that are no answer
#   XX capitals: … | …          the capitals, the first shown big
#   XX capital-aliases: … | …   more accepted spellings of the capitals
#   XX parts: ABC DEF …         World Bank codes summed for the country
#                               (default: its own); the first is the main
#   XX area: N | ok | wikipedia the area: a number, the World Bank's sum
#                               after all, or Wikipedia's figure
#   XX population: N YEAR       override
#   XX gdp: N YEAR              override (GDP per person, current US$)
#   XX highest: M EN | DE       the highest point, metres and name
#   XX via YY: EN | DE          why YY is a neighbour
#   XX flag: File.svg | Q…      the flag, a Commons file or another item's
#   XX flag-licence: LICENCE    a flag that is not in the public domain
